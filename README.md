# ServCheck

Australian automotive platform — checking if mechanic quotes are fair,
against real market data.

Being migrated from Base44 to a self-hosted Supabase + React/Vite stack.
See [`README-MIGRATION.md`](./README-MIGRATION.md) for migration status
and setup steps.

## Local development

```bash
npm install
npm run dev
```

Requires a `.env` file — copy `.env.example` and fill in the Supabase
project URL/anon key (already pre-filled for this project).
